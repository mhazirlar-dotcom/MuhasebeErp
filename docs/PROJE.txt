6. RESULT PATTERN (MERKEZİ)
---------------------------------------------------------------------
Konum: Accounting.Shared/Results/

Yapı:
- IResult: IsSuccess, IsFailure, Status, Message, Errors
- IDataResult<T> : IResult: + Data
- ResultStatus (const string):
  * Success, ValidationError, Unauthorized, Forbidden, NotFound,
    Conflict, BusinessRuleViolation, InternalError
- Error (record): Code, Message, Status, Field
- Result (non-generic): [JsonConstructor], factory metotlar
- Result<T> : Result, IDataResult<T>: [JsonConstructor]
- PagedResult<T> : Result, IDataResult<IReadOnlyList<T>>

ResultExtensions (Shared/Results):
- MapFailureAsync, EnsureAsync, EnsureFalseAsync
- ThenAsync (3 overload: generic, non-generic→generic, non-generic zincir)

QueryableExtensions (Core.DataAccess/Extensions):
- FirstOrNotFoundAsync<T>(predicate, message, ct) → Result<T>

ValidationExtensions (Core.Business/Extensions):
- ValidateErrorsAsync<TRequest> → IReadOnlyList<Error>?
- ValidateAsync<TRequest> → Result<TRequest>

ResultExtensions (Api/Extensions):
- ToActionResult(this IResult) → IActionResult
- Status → HTTP mapping:
  ValidationError→400, Unauthorized→401, Forbidden→403,
  NotFound→404, Conflict→409, BusinessRuleViolation→422,
  InternalError→500

ResultActionFilter (Api/Filters):
- Global filter: IAsyncActionFilter
- Result/Result<T> → ToActionResult() otomatik

HttpResponseExtensions (Desktop/Extensions):
- ReadResultAsync<T>(HttpResponseMessage, ct) → Result<T>
- ReadResultAsync(HttpResponseMessage, ct) → Result
- PropertyNameCaseInsensitive = true
- JsonException yakalama → InternalError
